Installer recovery: SIGKILL or a power failure can leave a channel lock. The
installer reports its path. Inspect its PID and remove the lock only after
confirming that no installer is running. Recovery does not discard source or app
data automatically.

The lockfile keeps its format version and every remaining package revision. Its
old `originHash` was removed with the Zip dependency. That field is optional in
SwiftPM's [resolved-file format](https://github.com/swiftlang/swift-package-manager/blob/main/Sources/PackageGraph/ResolvedPackagesStore.swift);
the next native package resolution can regenerate it. Native resolution with
the build script's strict pinning flag remains part of the pending Xcode build.

History CSV contains no stable transcription ID. Exact duplicate records are
therefore rejected conservatively. The scorer cannot prove that observations
with edited fields came from different transcription events.

## Application findings

The completed [provider report](details/providers.md) describes ten findings and
their fixes, including pipe deadlocks, cancellation, unsafe WAV decoding,
Whisper C-pointer lifetimes, context interleaving, download handling and archive
traversal. The completed [follow-up report](details/providers-followup.md) adds
limits before archive extraction, rollback on failed installation, pinned model
and archive downloads, and serialized FluidAudio operations.

All eight Whisper registry models and their seven Core ML archives now have
immutable URLs, expected byte sizes and SHA-256 values. The final integration
check independently matched all fifteen artifacts against the primary
[Hugging Face tree metadata at the pinned revision](https://huggingface.co/api/models/ggerganov/whisper.cpp/tree/5359861c739e955e79d9a303bcbc70fb988958b1).
The archive parser rejects unsafe names, symlinks, overlapping entries, more
than 256 entries and more than 2 GiB of expanded content. It streams extraction
into staging and handles the published large-v2 encoder's different root name.

The completed [recording report](details/recording.md) describes thirteen findings
and fixes. High-severity cases include cancelled imports saving stale results
and retranscription reporting success after a failed save. Other repairs remove
orphan files, preserve cancellation, stop public logging of transcript-derived
output, correct CSV quoting, prevent repeated resampling input, ignore stale
recording-start failures and preserve History metadata after failed enhancement.
The Core Audio callback ordering change is preventive hardening, not a reproduced
failure.

Parent integration also removes 32-bit frame-count conversions before bounding
audio chunks and waveform buffers. Very long files could otherwise trap even
though each read needs only a small buffer. Waveform generation rejects zero or
negative sample counts and caches separately for each requested sample count.
These macOS paths still need native verification.

The completed [persistence report](details/persistence.md) describes fifteen
defects and their repairs, including Auto Learn data loss, malformed backup
values, duplicate mode IDs, website spoofing, overlapping clipboard sessions,
unsafe cleanup paths, stale statistics and replacement text interpreted as a
regular-expression template. The portable tests exercise its Foundation-only
helpers.

That agent read 111 files in full, read logic sections of eleven, and scanned
66 others. The parent then read the remaining 77 files. The
[integration supplement](details/parent-integration.md) lists those paths,
additional repairs, corrected findings and copy/design follow-ups. It closes the
source-review gap without adding another agent round.

The ZIP finding comes from the pinned dependency's actual
[extraction implementation](https://github.com/marmelroy/Zip/blob/67fa55813b9e7b3b9acee9c0ae501def28746d76/Zip/Zip.swift#L169),
which appends an entry path and opens the resulting filename for writing. It is
an observed code path, not a claim about a published CVE.

## Remaining scope decisions

- macOS type checking, the `Compression` deflate branch, ProcessRunner process
  tests, native builds and device behavior remain unexecuted, as agreed.
- Whisper cancellation still waits for an in-progress native inference call.
  The application checks cancellation around that call; this audit does not add
  whisper.cpp's abort callback.
- A small PID-reuse window remains during process-tree termination. Eliminating
  it would require a different process-launch mechanism.
- FluidAudio's own downloaded-model integrity logic was not audited in full.
  Its pinned API and the Sendable types used by this app were checked.
- CSV preserves literal transcripts for benchmark scoring. A spreadsheet may
  interpret a transcript beginning with `=`, `+`, `-` or `@` as a formula. Import
  untrusted exports as text; a separate spreadsheet-safe export would be a
  product change.
- The recorder's linear resampler, failed audio-device switching and actual
  streaming finalization need device evidence before larger changes. Audio-only
  cleanup can still leave a stale stored URL if its database save fails after
  deletion; the transcription cleanup path saves before deleting audio.
- Retaining transcribe.cpp models between requests changes memory use. The
  audit does not silently change that policy to improve latency.
- Visual changes, including continuously animated processing indicators,
  require the user's mockup selection and were not implemented.
- Static language tables and translation wording were not proofread entry by
  entry. Their files and structure were checked. Third-party source trees are
  outside this repository's file coverage; specific dependency code was read
  where a finding required it.
